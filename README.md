# MIRAGE 22 — ASTROPICAL

Site estático, responsivo, preparado para publicação no Render.

## Publicação no Render

1. No [Render](https://dashboard.render.com/), escolha **New > Blueprint**.
2. Selecione o repositório `insidekeyco/mirage22-render`.
3. Confirme a configuração lida em `render.yaml` e realize o deploy.

Alternativa: **New > Static Site**, com `Build Command` vazio e `Publish Directory` igual a `.`.

## Privacidade

Este repositório é **público**. Por segurança, o arquivo `index.html` é uma versão **pública** da apresentação do evento. O planejamento interno completo, com honorários, projeções financeiras e capacidade estimada, **não foi publicado**. Mesmo em um repositório privado, uma URL padrão do Render é pública sem autenticação configurada.
